# Arquivos legados

Protótipos e artefatos antigos, mantidos só como registro. Nada do pipeline
atual depende deles.

| Caminho | O que é |
|---|---|
| `optimization/Teste/` | Primeiro protótipo DQN/TraCI (scripts `traci1`–`traci9`) sobre a rede fictícia |
| `optimization/EUA/` | Rede SUMO (`Node.*`) de testes iniciais |
| `models/dqn_traffic_model.keras` | Modelo Keras antigo, não carregado por nenhum script |
| `sumo/fictional/` | Rede fictícia (`RL.*`) usada pelo perfil `python/legacy/config.yaml` |

A prova de conceito com os detectores E2 do SUMO, a v1.0 do produto, continua
em `optimization/SP/`. O código Python legado está em `python/legacy/`.
